# نظام إدارة الموارد البشرية — الجهاز الوطني للتنمية
### نسخة Flask + SQLite

هذا المشروع تحويل للتصميم الأصلي (HTML/CSS ثابت) إلى تطبيق ويب فعلي
باستخدام **Flask** و **SQLite**، مع تفعيل وظائف **أول واجهتين** من النظام:

1. **تسجيل الدخول** (`/login`) — تحقق فعلي من قاعدة البيانات (اسم مستخدم + كلمة
   مرور مُشفّرة) وإنشاء جلسة (Session) حقيقية، بدل الانتقال الوهمي في النسخة
   الثابتة.
2. **لوحة التحكم** (`/dashboard`) — كل الأرقام والبطاقات (عدد الموظفين، طلبات
   الإجازة، الحضور اليومي، العقود المنتهية قريباً، الرسم البياني لآخر 7 أيام،
   وطلبات الإجازة المعلّقة) تُقرأ **مباشرة من قاعدة البيانات**، وتحتوي كذلك
   على إجراء فعلي لقبول/رفض طلب إجازة.

باقي الوحدات (الموظفون، الحضور، الإجازات، الرواتب، الأداء، التوظيف...) لا
تزال روابط "قيد التطوير" كما في التصميم الأصلي، وتُعرض بنفس هوية التصميم —
جاهزة لتُربط بقاعدة البيانات بنفس الأسلوب في المرحلة القادمة.

---

## 1. التثبيت

```bash
cd hr_system
python3 -m venv venv
source venv/bin/activate      # على ويندوز: venv\Scripts\activate
pip install -r requirements.txt
```

## 2. تعبئة البيانات الأولية (يُنشئ قاعدة البيانات ويملؤها)

```bash
python seed.py
```

سيُنشئ هذا الأمر قاعدة بيانات SQLite في `instance/hr_system.db` تحتوي على:
- 6 إدارات
- 8 موظفين (بنفس الأسماء والبيانات الظاهرة في التصميم الأصلي)
- مستخدمين للدخول
- طلبات إجازة (بعضها معلّق ليظهر في لوحة التحكم)
- سجلات حضور لآخر 7 أيام (لتغذية الرسم البياني والمؤشرات)

### بيانات الدخول التجريبية
| المستخدم | كلمة المرور | الدور |
|---|---|---|
| `hoda.hr` | `Hr@12345` | موظفة موارد بشرية (نفس المستخدمة في التصميم الأصلي) |
| `admin` | `Admin@12345` | مسؤول نظام |

## 3. تشغيل التطبيق

```bash
python app.py
```

ثم افتح المتصفح على: `http://127.0.0.1:5000`

## 4. هيكل المشروع

```
hr_system/
├── app.py                 # تطبيق Flask (المسارات / الجلسات)
├── models.py               # نماذج قاعدة البيانات (SQLAlchemy)
├── seed.py                  # تعبئة البيانات الأولية
├── requirements.txt
├── instance/
│   └── hr_system.db        # قاعدة بيانات SQLite (تُنشأ بعد تشغيل seed.py)
├── static/
│   └── css/style.css       # نفس تصميم النسخة الأصلية بالكامل
└── templates/
    ├── login.html          # واجهة تسجيل الدخول
    ├── base.html            # القالب المشترك (الشريط الجانبي + الشريط العلوي)
    ├── dashboard.html        # لوحة التحكم (بيانات حية)
    └── soon.html             # صفحة عامة للوحدات قيد التطوير
```

## 5. الخطوات التالية المقترحة

- ربط وحدة **الموظفون** بجدول `Employee` (عرض/بحث/فلترة/إضافة موظف).
- ربط وحدة **الحضور** بجدول `Attendance` (تسجيل حضور فعلي، QR/GPS).
- ربط وحدة **الإجازات** بجدول `LeaveRequest` (سجل كامل + أرصدة الإجازات).
- ربط وحدة **الرواتب** بجدول رواتب جديد (بدلات، خصومات، كشوف PDF).
- إضافة صلاحيات (Roles/Permissions) حقيقية حسب دور المستخدم.
- استبدال `SECRET_KEY` بقيمة سرّية فعلية عبر متغير بيئة قبل النشر.
